# 第二课：交互式 Agent

## 核心变化

第一课的用户任务是写死在代码里的：

```python
{"role": "user", "content": "请计算 23 加 19"}
```

第二课改成：

```python
user_task = input("请输入任务：").strip()
```

这样，Agent 的任务由运行时的用户输入决定。

## 关键观察

现在模型可以在两个工具之间选择：

```text
100 加 23 → add_numbers
12 乘以 8 → multiply_numbers
介绍一下北京 → 不调用计算工具
```

模型的选择主要依赖工具的名称、描述和参数 Schema。Python 程序则通过 `call_tool()` 根据工具名称找到真正的函数。

## 学习问题

1. 如果把 `multiply_numbers` 的描述改得很模糊，模型还能够正确选择它吗？
2. 如果用户说“先加 10，再乘 2”，当前 Agent 能否完成？为什么？
3. 如果用户输入空字符串，程序应该如何处理？
