# 第八课：向量相似度检索

## 1. 本课做什么

第七课用关键词交集计算相关度。本课将每个文本片段转换成数字向量，再使用余弦相似度排序。

```text
文本 → Token → TF-IDF 向量 → 余弦相似度 → Top-K
```

## 2. TF-IDF 的直觉

- TF：某个词在当前片段中出现得多不多；
- IDF：某个词在所有片段中稀不稀有；
- TF-IDF：常见但没有区分度的词权重低，能区分文档的词权重高。

## 3. 余弦相似度

余弦相似度比较两个向量的方向：

```text
1：方向非常接近
0：没有共同方向
```

本课输出的“余弦相似度”只是检索排序分数，不是模型置信度。

## 4. 重要限制

TF-IDF 仍然主要依赖词面重叠。例如“外部函数调用”和“连接第三方能力”语义相近，但如果没有共享关键词，仍然可能检索不到。

真正的语义检索会使用神经网络 Embedding，把相近含义映射到相近向量。下一阶段可以再学习 Embedding 和向量数据库。
