# 第十一课：两阶段检索与 RAG 评测

## 1. 为什么要重排序

向量数据库适合快速召回候选结果，但 Top-1 不一定就是最终最好的结果。

本课使用两阶段流程：

```text
第一阶段：向量数据库召回较多候选片段
第二阶段：结合语义距离和关键词分数重新排序
```

## 2. 候选数量

如果最终需要 `top_k=3`，本课先召回最多 9 个候选，再从中选出 3 个：

```python
candidate_k = min(max(top_k * 3, 5), 15)
```

真实系统中，候选数量需要根据数据规模和延迟进行调优。

## 3. 重排分数

本课使用学习用的组合分数：

```text
重排分数 = 0.7 × 语义分数 + 0.3 × 关键词分数
```

它不是通用最佳公式，只是帮助理解“多个信号融合”。

## 4. 评测

运行：

```powershell
python .\projects\11-rag-rerank\main.py --eval
```

评测会检查：期望来源是否出现在 Top-3 结果中。它衡量的是检索召回，不是最终答案质量。
