# 第六课：RAG 检索增强生成

## 1. RAG 是什么

RAG 的基本流程是：

```text
用户问题
  ↓
检索相关文档
  ↓
把文档片段放入上下文
  ↓
模型根据片段生成答案
```

本课的检索器使用关键词重叠，不使用 Embedding 和向量数据库，目的是先理解数据流。

## 2. 本课和记忆的区别

```text
对话记忆：保存之前发生的聊天内容
RAG：从外部知识库中找到当前问题相关的内容
```

## 3. 重点阅读位置

- `load_documents()`：加载本地 Markdown 文件；
- `tokenize()`：生成简单关键词；
- `search_knowledge_base()`：计算相关度并返回片段；
- `search_knowledge_base` 工具：让模型能够调用检索器；
- `messages` 中的 `role="tool"`：把检索结果交给模型。

3. 关键词检索可能漏掉哪些同义表达？
4. 为什么真实 RAG 系统通常会使用 Embedding 和向量数据库？
