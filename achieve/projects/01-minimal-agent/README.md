# 01 - 手写最小 Agent

这个实验不使用 Agent 框架，只使用 LLM 的工具调用能力，目的是看清楚 Agent 的核心循环。

## 运行

在学习工程根目录执行：

```powershell
python .\projects\01-minimal-agent\main.py
```

默认任务是让 Agent 调用 `add_numbers` 工具完成一个加法问题。

## 观察重点

- `messages` 为什么要保存每一轮对话？
- 模型返回的 `tool_calls` 包含什么信息？
- 为什么工具执行结果还要再次发回模型？
- 如果工具报错、模型一直调用工具，应该怎么处理？
