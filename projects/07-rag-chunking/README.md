# 07 - 文档切分、Top-K 与来源引用

第六课把整篇 Markdown 当作一个文档。本课把文档切成多个片段，并为每个片段增加来源和编号。

## 运行

```powershell
python .\projects\07-rag-chunking\main.py
```

建议输入：

```text
工具调用的完整流程是什么？
```

```text
持久化记忆和 RAG 有什么区别？
```

## 本课目标

- 理解为什么需要 Chunking；
- 观察一个文档如何被切分为多个片段；
- 理解 Top-K 参数如何影响检索结果数量；
- 给检索结果增加来源和 chunk 编号；
- 让最终回答带有简单的资料引用。

## 与第六课的区别

```text
第六课：文件 → 文件级检索 → 返回文件
第七课：文件 → 片段级检索 → 返回 Top-K 片段和来源
```
