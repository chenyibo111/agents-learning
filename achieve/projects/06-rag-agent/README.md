# 06 - RAG 检索增强生成

这一课使用本地 Markdown 文件作为知识库，手写一个最简单的检索器，不依赖向量数据库。

## 运行

```powershell
python .\projects\06-rag-agent\main.py
```

建议输入：

```text
什么是 Agent 的工具调用？
```

```text
短期记忆和持久化记忆有什么区别？
```

```text
RAG 的基本流程是什么？
```

## 本课目标

- 理解 RAG 的四个步骤：加载、切分、检索、生成；
- 观察检索结果如何作为工具结果进入 `messages`；
- 区分模型原有知识和外部知识库；
- 理解为什么真实项目会使用向量数据库和 Embedding。

## 本课实现

为了便于学习，本课使用关键词重叠进行检索：

```text
用户问题 → 关键词检索本地文档 → 返回相关片段 → 模型组织答案
```

这不是生产级检索器，但能帮助你看清 RAG 的基本结构。
