# 第九课：神经网络 Embedding 语义检索

## 1. 本课和第八课的区别

第八课：

```text
文本 → Token → TF-IDF 向量
```

第九课：

```text
文本 → Embedding 模型 → 语义向量
```

Embedding 模型通过训练学习语言模式，因此语义相近但词面不同的句子，可能得到方向接近的向量。

## 2. 归一化与点积

代码使用：

```python
normalize_embeddings=True
```

当两个向量都归一化后，它们的点积可以作为余弦相似度使用：

```python
scores = chunk_embeddings @ query_embedding
```

## 3. 模型缓存

第一次运行会下载模型。之后模型通常会从本地缓存加载。模型大小、下载速度和 CPU/GPU 会影响启动时间。
