# 08 - 向量相似度检索

第七课使用关键词交集计算相关度。本课使用一个纯 Python 实现的简化 TF-IDF 向量和余弦相似度检索器。

## 运行

```powershell
python .\projects\08-vector-retrieval\main.py
```

建议输入：

```text
工具调用如何把模型连接到外部能力？
```

```text
RAG 和聊天记录记忆有什么区别？
```

## 本课目标

- 理解文本如何转换成数字向量；
- 理解 TF、IDF 和余弦相似度的基本作用；
- 观察向量检索和关键词交集检索的区别；
- 理解“向量检索”与“语义 Embedding”仍然不是一回事。

## 重要说明

本课的 TF-IDF 是传统文本检索方法，不是神经网络 Embedding。它可以帮助你理解向量数据库背后的相似度计算，但同义词理解能力仍然有限。
