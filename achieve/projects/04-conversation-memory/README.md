# 04 - 对话记忆

这一课让 Agent 支持连续对话，并保留同一次运行中的历史消息。

## 运行

```powershell
python .\projects\04-conversation-memory\main.py
```

## 建议对话

依次输入：

```text
请计算 8 加 4
```

```text
把刚才的结果乘以 3
```

```text
再除以 2
```

输入 `exit` 或 `quit` 退出，输入 `clear` 清空当前对话记忆。

## 本课目标

- 理解短期记忆就是持续保存的 `messages`；
- 观察用户消息、助手消息和工具消息如何共同组成上下文；
- 理解为什么 Agent 需要控制上下文长度；
- 区分“同一次运行中的记忆”和“程序重启后的长期记忆”。
