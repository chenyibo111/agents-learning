# werewolf_arena 运行记录

本目录维护第 16 课狼人杀运行时的领域代码，以及问题和修复记录：

- [ISSUES.md](ISSUES.md)：记录运行中发现的问题。问题无论是否已经解决都先登记，解决后更新状态。
- [FIXES.md](FIXES.md)：记录已经完成并验证过的修复，通过 `I-xxx` 关联问题。

## 追加约定

1. 每次发现问题，在 `ISSUES.md` 末尾追加一个递增编号。
2. 每条问题只保留重点：日期、现象、影响、原因、状态。
3. 修复完成并验证后，在 `FIXES.md` 末尾追加对应记录，写明改动和验证命令。
4. 不记录 API Key、完整 Prompt、完整模型响应或其他敏感数据。
5. 未解决的问题保留为 `OPEN`；部分解决使用 `PARTIAL`，不要用修复记录掩盖遗留问题。
