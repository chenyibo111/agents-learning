# 第 15 课赛博小镇 Agent：实施计划

## 目标

完成一个标准库实现的离线多 Agent 社会模拟，覆盖事件驱动 tick、私有/公开状态隔离、规则 Policy 插拔、seed 重放、checkpoint 恢复、资源守恒和基础评测。

## 实施步骤

### 1. 领域模型与失败测试

- [ ] 定义 Agent、World、Observation、Action、Event、SimulationState。
- [ ] 先写状态隔离、交易、重放、恢复和评测测试。
- [ ] 运行测试确认新模块尚不存在导致失败。

### 2. 规则与策略

- [ ] 实现公开世界投影和私有记忆隔离。
- [ ] 实现交易、消息和拒绝规则。
- [ ] 实现 `Policy` 协议及三个确定性规则 NPC。

### 3. 引擎与持久化

- [ ] 实现 tick 编排、事件日志、seed 和 replay signature。
- [ ] 实现原子 JSON checkpoint、事件 JSONL 和报告写出。
- [ ] 实现中断后恢复并保证不重复 tick。

### 4. 评测、CLI 和课程资料

- [ ] 实现资源守恒、隐私泄露、事件统计和策略成本接口。
- [ ] 更新 CLI、README、课程进度和课程表。
- [ ] 保留 `--llm` 作为概念说明模式，不触发真实模型调用。

### 5. 验证

- [ ] 运行第 15 课专属测试。
- [ ] 运行项目入口测试和第 13、14 课回归测试。
- [ ] 运行 `git diff --check`，核对变更范围。
