# 03 - 多步 Agent 与错误处理

这一课让 Agent 处理多个连续步骤，例如：

```text
请先计算 8 加 4，再把结果乘以 3。
```

同时增加除法工具，观察工具发生错误时，Agent 如何收到错误信息并继续回答。

## 运行

在学习工程根目录执行：

```powershell
python .\projects\03-multi-step-agent\main.py
```

## 建议测试

```text
请先计算 8 加 4，再把结果乘以 3。
请计算 100 除以 4。
请计算 10 除以 0，并说明发生了什么。
```

## 本课目标

- 理解 Agent 为什么需要多轮循环；
- 观察工具结果如何成为下一步的输入；
- 理解最大步数的作用；
- 学习将工具错误转换为模型可以理解的结果。
